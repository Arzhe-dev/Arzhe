# 🌙 Arzhe — Optimiseur Gaming Premium

Application Windows native qui optimise ton PC pour le gaming : analyse matérielle,
13 modules réversibles, points de restauration automatiques.

## ✨ Fonctionnalités

- 🖥️ **Analyse matérielle** automatique (CPU, GPU, RAM, disque) via WMI
- ⚡ **13 modules d'optimisation** réversibles
- 🛡️ **Point de restauration** créé automatiquement avant chaque modification
- 🎮 **Tweaks spécifiques** pour Valorant, Fortnite et Roblox
- 📜 **Journal live** avec affichage en temps réel
- 📄 **Export du rapport** .txt après optimisation

## 📥 Téléchargement

**[⬇️ Télécharger Arzhe_Setup_1.0.0.exe](website/download/Arzhe_Setup_1.0.0.exe)**

Windows 10 / 11 · 64-bit · ~70 Mo

### Installation

1. Lance `Arzhe_Setup_1.0.0.exe`
2. Si Windows affiche un avertissement SmartScreen, clique sur **Informations complémentaires** → **Exécuter quand même**
3. Suis l'assistant
4. Un raccourci **Arzhe** apparaît sur ton bureau

## 🚀 Utilisation

1. Lance Arzhe (accepte l'UAC)
2. Clique **Démarrer l'analyse**
3. Sélectionne les modules à appliquer
4. Clique **Lancer l'optimisation**
5. Un point de restauration est créé automatiquement
6. Exporte le rapport à la fin
